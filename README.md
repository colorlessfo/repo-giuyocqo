# 奇遇 DDL

一个中文任务与学期日程网站。黑色与深蓝渐变夜空、随机白色星河、橙黄像素火光、大字体，个人待办优先显示。

本仓库最初仅有 README 和 LICENSE，没有取得旧站「余量 DDL」的源码或数据。本版本在当前仓库独立实现，尚未替换或迁移旧站，也没有确认旧站的历史功能。

## 已实现

- 自定义账号和密码注册、登录、修改密码；无需手机号、邮箱、验证码或 ChatGPT 账号。旧邮箱账号仍可登录。密码采用 scrypt 派生，登录会话为 HttpOnly Cookie。
- SQLite 或独立 PostgreSQL 数据库保存、账号隔离、多设备定时同步、版本冲突提示、离线队列和幂等重试。体验空间使用本机示例数据，与正式账号隔离。
- 个人任务增删改、完成与恢复、精确 DDL、自定义分类和小伙伴。删除分类保留其任务。
- 计划用时 1 分钟至 365 天；任务开始时间 = DDL − 计划用时。
- 未来七日日程、跨天拆段显示、当前时间线、默认锁定、一次解锁后连续移动、保持时长并更新 DDL、撤销。移动按 15 分钟对齐。
- 00:00–06:00 只压缩视觉高度，保留完整的时间与反向坐标换算。
- 课程独立建模、有限教学周、单双周、学期起始周一和节次配置；课程与待办分别显示/隐藏。
- 本机中文图片识别、可编辑校对、确认导入、重复课程去重；识别不确定的信息留空。原图不上传服务器。
- 日程可一键铺满网页，支持七天总览与单日详情。放大时保留解锁、撤销和编辑状态；手机总览无需横向拖动才能看齐七天。
- 四位原创像素火把动物与星空；可暂停动画，尊重系统减少动态效果设置。首页待办使用磨砂玻璃卡片。日程任务格采用用户提供代码中的 Canvas 像素火焰，不显示宠物。火焰调节与拖动共用锁定状态；解锁后可调整参数，按账号保存。接入说明见 [火焰模块](docs/FLAME-INTEGRATION.md)。
- 星空由浏览器随机生成白色星点与疏密自然的银河，大小、亮度和闪烁节奏各不相同，没有平铺贴图或规则阵列。页面内切换保留当前星空，重新打开生成新星空。
- 白色星点提高了可见度，亮度按独立随机相位和节奏渐明渐暗。右上角可暂停装饰动画，系统减少动态效果时保留静态星空。
- 冒险地图入口、任务分类与“未分类”支持手柄拖动排序和方向键排序，按账号保存。手机可从“编辑分类”调整分类和冒险地图顺序。
- 左下角“小狐狸”改为“点亮火把，开始专注”：默认或自定义 1–480 分钟，约四秒的可跳过像素狐狸点火过场后显示倒计时。支持暂停、继续、提前结束、刷新恢复及悬浮倒计时；没有树屋、藤蔓或兑换系统。
- 专注分析显示实际专注时间、完成段数、完成比例、7/30 天每日柱状图、近 31 天时段分布和最近 50 段记录。暂停不计入时长，跨午夜按当前设备时区拆分，提前结束保留实际用时并明确标记。正式账号服务端计时、冲突保护和幂等重试。详见 [专注计时与分析](docs/FOCUS.md)。
- 记事本完整页面与悬浮窗口共用同一批笔记，支持搜索、归档、恢复、删除、拖动、触摸缩放、宽高和圆角调节。位置与外形按设备保留，内容和归档按账号同步。
- JSON 备份合并恢复（含笔记与归档）、ICS 日历导出。

## 当前边界

- 已有生产入口 https://qiyu-ddl.onrender.com/ ，用户此前提供的 Render 截图显示旧版部署成功。本轮版本只有部署完成后才会出现在这个原网址；本地截图和测试不能视为生产验证。
- **按用户要求取消短信和邮箱注册要求，只用账号密码。** 当前不提供密码找回，请妥善保管。
- **关闭网页后不会系统推送。** ICS 是一次性快照，包含任务截止前 30 分钟提醒，是否触发由日历软件决定。
- 课程点击编辑整个重复规则，暂不支持拖动课程，避免无提示改变整学期。
- OCR 能识别文字并按星期列和文字块提取候选课程，但截图版式和清晰度会影响效果。不能自动判断的时间、周次等必须手动补充；需逐门勾选已校对。
- 旧站与新站是不同来源，不能直接读旧站浏览器数据。目前只支持本版本 JSON；旧版迁移需先取得其导出文件并确认字段格式。
- 时间以设备本地时区显示，DDL 保存为 UTC；教学周按日历日期计算。多设备日常使用应设置一致的时区。

## 本地开发

需要 Node.js 24 或更高版本（使用其内置 SQLite），无需另装数据库。

```sh
npm ci --cache /tmp/qiyu-npm-cache
npm run dev
```

默认端口 3000。`postinstall` 会从已锁定的 npm 包复制中文、英文 OCR 模型到 `public/ocr`。所有识别资源由本站提供，不依赖第三方识别接口。

```sh
npm run build
npm start
```

生产环境默认启用 Secure Cookie，要求 HTTPS。在本机检查生产构建时可临时设置 `COOKIE_SECURE=false`；公开部署不要设置它。

运行检查：

```sh
npm test
npm run test:e2e
```

浏览器测试优先使用 `/usr/bin/chromium`；其他机器需先运行 `npx playwright install chromium`。测试数据库写入临时目录，不会使用你的正式数据库。

## 公开部署

应用是一个 Node.js 服务，同时提供网页和 API。支持两条部署路线：免费实例连接独立 PostgreSQL 数据库；或者使用持久磁盘保存 SQLite。两者均需通过 HTTPS 对外提供服务。

不能只上传 `dist` 到静态网站平台，那样没有账号和云端同步。不要用重启即丢弃磁盘的实例保存真实任务。用户无需拥有 ChatGPT 账号，但必须能正常访问选定托管平台的公开域名。

有服务器时：

1. 复制 `.env.example` 为 `.env`，设置真实 `PUBLIC_URL`。
2. 执行 `docker compose up -d --build`。
3. 用现有 HTTPS 反向代理把域名转到本机 3000 端口；不要直接把开发服务器作为公网服务。
4. 检查 `/api/health`，实际注册两个账号，验证账号隔离、手机与电脑同步、重启后数据仍在。
5. 持久保留 `qiyu-data` 卷，并定期备份。SQLite 在线备份应使用数据库备份接口或停机后复制完整数据目录，不能在写入中只拷贝一个数据库文件。

在支持持久磁盘的 Node 托管平台部署：

- 安装：`npm ci`；构建：`npm run build`；启动：`npm start`。
- 设置 Node.js 24+、`NODE_ENV=production`、`TRUST_PROXY=1`、真实 `PUBLIC_URL`。
- 把持久磁盘挂载目录设置为 `DATA_DIR`。若平台使用 Docker，也可直接构建本仓库 Dockerfile。
- 一个实例使用一个持久数据库；暂不支持多个应用实例共享这个 SQLite 文件。

根目录 `render.yaml` 已切换为 **Render Free + 独立 PostgreSQL**，必须在服务端安全配置 `DATABASE_URL` 后才能部署。步骤见 [免费部署说明](docs/FREE-DEPLOY.md)。免费额度、休眠及数据库暂停条件以开通时平台规则为准，不承诺无条件永久免费。

原付费实例与磁盘的配置保存在 `deploy/render-sqlite.yaml`，只有确认费用后才能使用。使用该路线时必须保留磁盘，并设置 `ALLOW_PERSISTENT_SQLITE=true`；不要在免费临时磁盘实例设置这个开关。

实际检查结果和边界见 [验证记录](docs/VERIFICATION.md)。

域名、服务器、持久磁盘和超过免费额度的数据库资源可能产生费用。没有登录授权或费用确认时，不应替用户开通收费资源。

## 更新原网站

继续使用 Render 中已创建的 `qiyu-ddl` 服务，部署分支保持 `qiyu-ddl`。推送新提交后，如果启用了自动部署，Render 会构建新版本；否则从服务页面选择 **Manual Deploy → Deploy latest commit**。确认 Live 后刷新原网址即可，不用创建新服务、更换域名或重新注册账号。

保留现有 `DATABASE_URL`、`DATABASE_SSL_CA` 和其他服务端设置。笔记使用已有私有 `entities` 表里的 `notes` 集合，不需要新数据库、短信服务或额外密钥。旧缓存和旧备份缺少 `notes` 时会补为空列表，已有任务和待同步队列仍然保留。导入旧备份不会删除现有笔记。

记事本每次输入先保存账号隔离的本机草稿，短暂防抖后交给同步队列。离线或冲突时保留本机内容；同步状态入口可以处理冲突。切换设备前应确认已同步。窗口外形和位置按设备记录，以免电脑窗口尺寸把手机内容挤出屏幕。

注意：服务器已保存笔记后，不应直接回滚到完全不认识 `notes` 集合的旧后端；回退版本也须保留笔记快照的兼容支持。

本轮侧栏顺序保存在原有 `settings.sidebar`，旧设置请求会保留排序。专注记录在原数据库自动建立私有 `focus_profiles` / `focus_history` 表，复用原会话和重试收据，不需要新服务、环境变量或密钥。原任务 JSON 备份仍包含待办、分类、课程、笔记和设置；完整备份专注记录需同时保留数据库中的新表与 `mutations`。
