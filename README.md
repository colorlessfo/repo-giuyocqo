# 奇遇 DDL

一个中文任务与学期日程网站。暖白、蓝紫配色，大字体，个人待办优先显示。

本仓库最初仅有 README 和 LICENSE，没有取得旧站「余量 DDL」的源码或数据。本版本在当前仓库独立实现，尚未替换或迁移旧站，也没有确认旧站的历史功能。

## 已实现

- 邮箱和密码注册、登录、修改密码；无需 ChatGPT 账号。密码采用 scrypt 派生，登录会话为 HttpOnly Cookie。
- SQLite 持久保存、账号隔离、多设备定时同步、版本冲突提示、离线队列和幂等重试。体验空间使用本机示例数据，与正式账号隔离。
- 个人任务增删改、完成与恢复、精确 DDL、自定义分类和小伙伴。删除分类保留其任务。
- 计划用时 1 分钟至 365 天；任务开始时间 = DDL − 计划用时。
- 未来七日日程、跨天拆段显示、当前时间线、默认锁定、一次解锁后连续移动、保持时长并更新 DDL、撤销。移动按 15 分钟对齐。
- 00:00–06:00 只压缩视觉高度，保留完整的时间与反向坐标换算。
- 课程独立建模、有限教学周、单双周、学期起始周一和节次配置；课程与待办分别显示/隐藏。
- 本机中文图片识别、可编辑校对、确认导入、重复课程去重；识别不确定的信息留空。原图不上传服务器。
- JSON 备份合并恢复、ICS 日历导出。

## 当前边界

- **尚未获得公开托管授权，不能把本地运行视为已上线。** 开发环境运行中进程也不保证长期存在。
- **没有接通手机验证码、邮箱验证、邮件找回密码。** 当前采用邮箱和密码，注册界面如实说明。
- **关闭网页后不会系统推送。** ICS 是一次性快照，包含任务截止前 30 分钟提醒，是否触发由日历软件决定。
- 课程点击编辑整个重复规则，暂不支持拖动课程，避免无提示改变整学期。
- OCR 能识别文字并按星期列和文字块提取候选课程，但截图版式和清晰度会影响效果。不能自动判断的时间、周次等必须手动补充；需逐门勾选已校对。
- 旧站与新站是不同来源，不能直接读旧站浏览器数据。目前只支持本版本 JSON；旧版迁移需先取得其导出文件并确认字段格式。
- 时间以设备本地时区显示，DDL 保存为 UTC；教学周按日历日期计算。多设备日常使用应设置一致的时区。

## 本地开发

需要 Node.js 24 或更高版本（使用其内置 SQLite），无需另装数据库。

```sh
npm ci --cache /tmp/qiyu-npm-cache
npm run dev
```

默认端口 3000。`postinstall` 会从已锁定的 npm 包复制中文、英文 OCR 模型到 `public/ocr`。所有识别资源由本站提供，不依赖第三方识别接口。

```sh
npm run build
npm start
```

生产环境默认启用 Secure Cookie，要求 HTTPS。在本机检查生产构建时可临时设置 `COOKIE_SECURE=false`；公开部署不要设置它。

运行检查：

```sh
npm test
npm run test:e2e
```

浏览器测试优先使用 `/usr/bin/chromium`；其他机器需先运行 `npx playwright install chromium`。测试数据库写入临时目录，不会使用你的正式数据库。

## 公开部署

应用是一个 Node.js 服务，同时提供网页和 API。需要支持**持久磁盘**的托管平台，或一台有 Docker 的服务器，配合 HTTPS 域名。

不能只上传 `dist` 到静态网站平台，那样没有账号和云端同步。不要用重启即丢弃磁盘的实例保存真实任务。用户无需拥有 ChatGPT 账号，但必须能正常访问选定托管平台的公开域名。

有服务器时：

1. 复制 `.env.example` 为 `.env`，设置真实 `PUBLIC_URL`。
2. 执行 `docker compose up -d --build`。
3. 用现有 HTTPS 反向代理把域名转到本机 3000 端口；不要直接把开发服务器作为公网服务。
4. 检查 `/api/health`，实际注册两个账号，验证账号隔离、手机与电脑同步、重启后数据仍在。
5. 持久保留 `qiyu-data` 卷，并定期备份。SQLite 在线备份应使用数据库备份接口或停机后复制完整数据目录，不能在写入中只拷贝一个数据库文件。

在支持持久磁盘的 Node 托管平台部署：

- 安装：`npm ci`；构建：`npm run build`；启动：`npm start`。
- 设置 Node.js 24+、`NODE_ENV=production`、`TRUST_PROXY=1`、真实 `PUBLIC_URL`。
- 把持久磁盘挂载目录设置为 `DATA_DIR`。若平台使用 Docker，也可直接构建本仓库 Dockerfile。
- 一个实例使用一个持久数据库；暂不支持多个应用实例共享这个 SQLite 文件。

本仓库还提供 `render.yaml`：可在 Render 连接本仓库的 `qiyu-ddl` 分支，通过 Blueprint 审阅部署配置。配置使用 Starter 实例和 1 GB 持久磁盘，**涉及费用，创建前必须在 Render 核对并确认**。注册、保存这个配置文件均不代表已部署，也不会自行开通资源。

实际检查结果和边界见 [验证记录](docs/VERIFICATION.md)。

域名、服务器、持久磁盘和短信服务可能产生费用。没有登录授权或费用确认时，不应替用户开通收费资源。
