# 上传火焰模块接入

来源：用户提供的 `code_artifact.html`（SHA-256 `0170038b0f0f6bfdf42fcef85bf7c992bccbe26d83dcbbc43dbc6236463214a5`）。只移植其第 2、3、4 部分的噪声、调色与 Canvas 火焰，以及参数调节逻辑。没有引入示例任务、固定 14–24 点网格、拖动实现、Tailwind CDN、远程字体或狐狸精灵。

## 参数与操作

| 参数         | 默认 | 范围        |
| ------------ | ---- | ----------- |
| 燃烧速度     | 0.52 | 0.2–1.6     |
| 火舌幅度     | 1.18 | 0.6–1.6     |
| 黄色核心比例 | 0.48 | 0.35–0.65   |
| 像素大小     | 4 px | 3–7 px      |
| 火焰动画     | 播放 | 播放 / 静止 |

前三项使用 0.01 步长，让原代码的默认值 0.52、1.18、0.48 可以精确显示和调节。

日程表火焰按钮展开参数面板。面板可以在锁定时查看，但滑块、动画开关、恢复默认全部禁用，修改回调也检查锁定状态。它们与拖动共用 Schedule 的同一个 locked 状态；一次解锁后可以连续调节和移动，保存不会自动重新锁定。重新锁定前将最后一次调整送入保存队列。

大任务格不显示宠物，绘制函数没有包含上传代码里的 FOX_SPRITE；任务中的 mascot 数据仍用于其他既有位置。

## 接入原系统

- `shared/flame.mjs` 保留原始 hash / Hermite 插值 / 两层噪声 / 热度取色 / 四边火舌 / 火星的计算。
- `src/FlameCanvas.tsx` 用共享的 24fps 上限循环、尺寸与可见性观察器绘制。屏外及隐藏页面暂停；暂停动画和减少动态效果时保留静态帧。长任务只计算当前可见的像素行，坐标仍相对于整段任务。火焰严格在任务时间格内。
- `src/FlameTuner.tsx` 提供控件；`src/flame.css` 隔离样式，保留既有首页和记事本。
- 火焰设置保存在账号 settings.flame 中，继承原有离线队列、版本冲突和备份。学期编辑保留火焰，旧客户端没有 flame 字段时服务端也保留当前值，并维持旧保存请求的幂等格式。
- 保留原来的 DDL/计划用时模型、凌晨压缩、跨天任务、重复课程、撤销、全屏和手机视图。

星空与首页小伙伴的动画按钮控制原有装饰；Canvas 火焰由锁定面板中的“火焰动画”控制，避免通过其他按钮绕过火焰参数锁。
