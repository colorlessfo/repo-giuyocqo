# 点亮火把，开始专注

## 页面与操作

首页保留已选定的磨砂玻璃待办和黑蓝夜空。星星全部为白色，使用浏览器随机数独立生成位置、大小、亮度和闪烁相位，不使用平铺图。明暗变化比上一版明显，闪烁周期约 3–9 秒。暂停装饰动画和系统减少动态效果均会保留可见的静态星空。

左侧入口和分类的右侧有六点手柄：拖动可调整先后顺序，聚焦手柄后按上下方向键也可以。手机从“编辑分类”进入，分类可触摸拖动，展开“调整冒险地图顺序”可调整底部导航。顺序随账号同步；新分类自动追加，删除分类不删除任务。

左下角狐狸的文案为“点亮火把，开始专注”，点击以最近选择的时长开始（首次 25 分钟）。旁边设置图标和“专注分析”页的“点亮火把”可先选择内容与时长，范围 1–480 分钟。手机提供同名入口。

开始后，小狐狸以大像素形象跑入页面、落脚、点亮火把，暖光向外扩散，约 3.8 秒后进入计时器。支持跳过和 Escape；减少动态效果时缩短过场。未引入树屋、藤蔓或装扮商城。

计时器显示剩余分钟与秒，每秒递减。暂停时剩余时间保持不变，恢复后继续递减；收起窗口后，悬浮栏显示同一份倒计时，替代普通待办状态岛，避免重叠。刷新或另一设备登录后可继续，目标时间到达后保存一次完成记录。提前结束需确认，已用时间保留并标记为提前结束。

按最新反馈简化计时窗口：隐藏大标题、介绍、装饰标签、计划/已用说明和底部常驻小字，只保留狐狸、剩余时间、进度与操作。自填的专注事项仍显示；错误、离线和等待同步等必要反馈按需显示。弹窗保留不可见的无障碍名称与说明。

“专注分析”标题下不再显示说明小字。页面包含今天与累计实际用时、完成段数、完成比例，7/30 天每日柱状图、近 31 天时段分布和最近 50 段记录。点击柱可查看当天用时与段数，也可展开表格。没有记录时显示空态，不生成示例成绩。图表中包含实际发生的提前结束时间，暂停间隔排除，跨午夜拆到对应日期；时区显示在时段图下。

## 数据与兼容

- `settings.sidebar` 是原设置上的可选字段，保留入口及分类顺序；旧客户端不传此字段时，服务端保留已保存的值。学期编辑、火焰调节及旧版备份兼容。
- `focus_profiles` 以账号保存版本及唯一当前专注，`focus_history` 保存已结束的记录及 UTC 计时间隔。应用启动时自动建表，不删除旧数据，不依赖新服务或凭据。
- `/api/focus` 和 `/api/focus/action` 复用现有登录、来源校验、限流及账号数据库锁。开始、暂停、继续和结束都使用服务端时间；客户端不能指定其他用户或用本机时钟提前完成。
- 操作在请求前写入账号隔离的本机缓存，同一操作编号对应同一份服务端收据（原 `mutations` 表中的 `focus:` 命名空间）。已生效但响应丢失时，刷新后重试不会重复保存记录。
- 两设备同时修改时检查版本，返回最新专注并提示，不静默覆盖。同一账号同时只保留一段当前专注，约六秒同步并在页面恢复可见、联网或窗口获得焦点时刷新。
- 正在运行的计时按截止时刻与校准时间显示，避免把浏览器后台节流造成的漏帧当成暂停。离线时已有倒计时继续，新操作等待联网确认。系统关闭网页后的推送尚未提供。
- 日统计按设备 IANA 时区拆分 UTC 区间，支持跨午夜、非整点偏移及夏令时。累计总时长从全体历史记录统计；每日及时段图只查询近期记录；历史列表显示最近 50 条。
- 体验空间与正式账号分开，体验计时仅保存在本机。专注不会自动改变待办的完成状态、DDL 或计划用时。

## 发布与验证

沿用 `qiyu-ddl` 分支、原 Render 服务及现有 PostgreSQL 配置。无须新增变量，保留 `DATABASE_URL`、官方 CA 和既有账号数据。部署完成后刷新原网址；本地测试与推送不等于已确认公网部署。

原任务 JSON 备份包含侧栏顺序，不包含独立专注历史。完整恢复专注数据需数据库备份，保留 `focus_profiles`、`focus_history`、`mutations` 和账号表；旧版回退不主动删除这些表。

检查覆盖剩余时间实际递减、暂停不递减、悬浮栏倒计时、可跳过的点火过场、真实鼠标/触摸拖动、键盘排序、刷新和另一设备恢复顺序、响应丢失重试、计时与历史持久化、账号隔离、跨午夜及时区统计。浏览器测试仅在隔离测试账户的数据库中准备最后几秒；生产接口没有测试加速入口。
