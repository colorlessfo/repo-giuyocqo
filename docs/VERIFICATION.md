## 部署配置

`render.yaml` 现为 Free 网页实例 + 外部 PostgreSQL，连接串必须只在 Render 服务端安全配置。免费计划有休眠、额度或闲置暂停条件，具体以开通时平台规则为准。

原付费持久磁盘路线保留在 `deploy/render-sqlite.yaml`，不得在未确认价格时创建付费资源。

开发：`npm run dev`；生产：`npm run build && npm start`。公网必须使用 HTTPS，外部数据库必须验证 TLS 证书。
