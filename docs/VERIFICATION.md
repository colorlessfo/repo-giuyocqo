# 奇遇 DDL 验证记录

验证日期：2026-11-04。以下结果来自当前开发环境、Chromium 触屏模拟、本地 Docker 和独立 PostgreSQL。用户已提供原网站 https://qiyu-ddl.onrender.com/ ，并在此前截图中展示 Render 旧版部署成功；本次新版的公网部署和实际设备效果仍需在 Render 确认。

## 本次交付范围

- 主界面采用用户最终选定的磨砂玻璃待办卡片，黑色与深蓝渐变星空、橙黄强调色、不同层次的分类，以及四位原创像素火把动物。中文任务标题保持 20px 以上。
- 左侧及手机底部的“我的课程”替换成“记事本”。课程导入、课程规则管理、学期及节次设置均可从日程表进入，数据没有删除。
- 记事本完整页面和悬浮窗口共用同一组笔记，支持搜索、编辑、归档、恢复、删除、内容同步、JSON 备份。悬浮窗口可触摸移动和缩放，支持宽高、圆角及预设外形，窗口位置按账号和设备保留。
- 输入时同步保存本机草稿，900ms 防抖后进入现有幂等保存队列。原始编辑版本会一直带到服务器，期间另一设备修改同一笔记会提示冲突。正文保留空白、缩进和换行。
- 日程表放大后铺满网页视口，同一组件保持挂载，保留解锁和撤销记录。支持完整七天总览、单日详情、回到当前时间，课程与任务可分别隐藏。
- 火焰已按用户上传的 code_artifact.html 移植为 Canvas 绘制，替换旧 SVG 实验，未引入附件的布局、示例任务、外部依赖和宠物绘制。任务格中没有宠物。参数与拖动共用锁定状态，锁定时控件禁用且回调守卫；解锁可连续调节，保存不自动上锁。
- 移除平铺星图和规则排列，使用浏览器随机数生成白色星点与银河。星点位置、大小、亮度及闪烁节奏独立变化，银河沿随机星带疏密分布；页面切换保留当前星空，重新载入生成新星空。保留磨砂玻璃卡片与记事本布局。

## 发布和使用

仍使用同一个 Render 服务和 `qiyu-ddl` 分支；不要新建网站、数据库或收费资源。保留现有 `DATABASE_URL`、`DATABASE_SSL_CA`、`TRUST_PROXY` 等服务端变量。笔记使用原有私有 `entities` 表中的 `notes` 集合，火焰保存在 settings.flame 中，不需要新表、短信或新密钥。

Render 自动部署开启时，推送提交后会构建；否则选择 Manual Deploy → Deploy latest commit。需确认 Live，然后刷新原网址。已经打开的网页不会强制刷新正在编辑的内容。

旧浏览器缓存和旧 JSON 备份没有 notes 字段时补为空列表，任务和待同步队列继续保留。导入旧备份不会清除已有笔记。后端保存过笔记后，回退版本也必须认识 notes 集合，不能直接回滚到完全不兼容的旧快照实现。

## 实际边界

- 当前云环境通过代理访问原 Render 网址时返回目标访问拒绝（Tunnel 403）。这不能判断网站本身是否故障，也不能作为新版已上线的证明。
- 手机测试是 Chromium 触屏模拟，未覆盖所有真机、Safari、键盘和低内存设备。磨砂玻璃在不支持 backdrop-filter 的旧浏览器上会保留半透明底色及边框。
- 笔记内容和归档按账号同步；窗口尺寸和位置为设备级偏好。离线保存先留在本机，切换设备前须确认同步成功。体验模式只保存在当前浏览器。
- 尚未取得原「余量 DDL」旧站源码或导出数据，没有自动搬迁旧站数据。
- 当前仅账号密码登录，没有短信、邮箱验证码或密码找回。
- 关闭网页后没有系统推送；ICS 提醒由日历应用决定。OCR 仍需人工校对，不保证任意截图都能识别。
- Render 和数据库免费方案的休眠、容量及用量以平台规则为准。
